## 🛠️ Setting Up

### Install Python
```bash
# Check if Python 3 is installed
python3 --version

# If not installed, visit: https://www.python.org/downloads/
```

### Recommended IDE/Editors
- **VS Code** (with Python extension)
- **PyCharm** (Community Edition is free)
- **Sublime Text** with Python plugins
- **Vim** / **Emacs** for terminal lovers

### Virtual Environment (Recommended)
```bash
# Create virtual environment
python3 -m venv venv

# Activate it
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# Install useful packages
pip install ipython pytest black flake8
```
